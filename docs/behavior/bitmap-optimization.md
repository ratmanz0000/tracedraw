# Optimize Raster

Right-click a single bitmap and choose Optimize Raster on desktop.
Compare the stored PNG with the decoded candidate in color, alpha or
difference mode. Both previews share the same region and zoom. Apply
is available only for a smaller, fully verified replacement and is one
Undo step. The initial pass supports plain embedded RGB/RGBA8 PNG
up to 12 megapixels and 64 MiB encoded. It does not change resolution,
build tile caches or rewrite profiled, linked or effect-backed images.
